Key non-negotiable rules:
- Home = Launch Pad ONLY: greeting + "Start New Order" CTA + Today's Tasks + optional quick nav links
- No Workbench analytics tiles, no Recent Jobs section on Home
- New Order Flow = guided wizard, no long forms
- Job screen = Execution Engine with dynamic Next Step button
- Schedule screen = temporal intelligence layer (Today/Tomorrow/This Week grouping)
- WhatsApp = primary communication layer, not secondary
- Monetization: visible but never blocking core workflows
- AI: simulated, collapsible, never blocking
- Notifications: short, action-driven, single-tap deep-link to job
